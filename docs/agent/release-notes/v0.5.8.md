## What's new in Armory 0.5.8

**Armory opens on every lab computer again. If it can't, it tells you why.**

On some school computers, Armory 0.5.5 to 0.5.7 did not open at all, even after a fresh install, and showed no message. A cleanup step that removes old copies of Armory ran before the window, and when the school's computer settings stopped that step, Armory quietly closed.

- **The cleanup no longer stops Armory.** It now runs after the window is open. If it can't finish, Armory keeps running and saves a short report for the website.
- **Armory says when it's stuck.** If Armory is already running but not answering, opening it again shows a message: restart the computer, or end IdeaArmory in Task Manager, then open Armory again.
- **A startup error is shown, not hidden.** If something goes wrong while Armory starts, a message says what it was and where the details are saved.

Starting at sign-in stays quiet, and Check out and open from notifications works the same as before.

**On a computer where Armory 0.5.7 never opens,** run `IDEAArmory-win-Setup.exe` from this release once. That computer can't update itself until Armory opens. It keeps your Armory folder, your files and your sign-in.
