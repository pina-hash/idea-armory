## What's new in Armory 0.4.1

Install 0.4.1 once on every computer with `IDEAArmory-win-Setup.exe`. It keeps your Armory folder, your files and your sign-in. 0.4.0 was never published with its installers, so everything 0.4.0 brings is in 0.4.1 too (below). **From now on Armory updates itself:** it finds each new version, downloads it while you work, and runs it the next time Armory opens.

**Mentors, CAD leads and instructors can organize around check outs.** Rename or move a file, or rename a folder, even while someone else has files in it checked out. Their check outs stay theirs: nothing is force checked in, and nothing they haven't checked in is set aside. On their computer the file moves to its new place by itself as soon as SolidWorks lets go of it, with every save in it, and Armory tells them who moved it and that it's still checked out to them. Students still can't rename files someone else has checked out. Deleting a folder still needs its files checked in first.

**Quicker on lab computers.** Armory no longer opens every file in your Armory folder each time it looks for changes. Files that aren't checked out on that computer are checked by their size and date alone, and only the files you're working on are opened, so a quiet look over a large vault no longer opens hundreds of files.

**Check in answers sooner.** A click that came while Armory was looking over your folder used to wait for that look to finish and then look over the whole folder again. Now it goes on from the look that just finished. Armory still reads the file itself before it lets the check out go, so a save made in that moment is never lost.

**Fixed:** the installers for 0.4.0 were never built, because one of Armory's own checks failed on Windows. That check is fixed, and 0.4.1 is built and tested the same way.

## Also in 0.4.1, from 0.4.0

**The status holds still.** The status no longer flicks between "All saved" and "Updating" every second. A quick look for your team's changes keeps the status as it was, the status keeps the same height whatever it says, and a new **Now** line always says what Armory is doing right now ("Watching your folder for saves.", "Downloading 412 of 1,280 files", "Waiting for you to close 1 file in SolidWorks to check it in.").

**Live updates stay connected.** Armory renews its sign-in for live updates well before it runs out, even on a computer whose clock is a few minutes off, so your team's changes keep arriving the moment they happen.

**Files SolidWorks still has just wait.** "Being used by another process" is no longer a red error. The file shows as waiting, and it uploads a few seconds after SolidWorks lets go of it.

**Save As from a template you didn't check out.** Open a file you haven't checked out (it opens read-only), change it, and use **Save As** to save it under a new name in your project folder. The new file is added to Armory by itself as soon as SolidWorks lets go of it. The template stays as it was.

**Nothing stays stuck.** If Armory ever gets stuck looking for changes, it starts again by itself within two minutes instead of waiting for hours.

**A file saved in a newer SolidWorks goes up, with a warning.** A part saved in SolidWorks 2026 in a project that uses 2025 is no longer held back on your computer. It goes to the team, and everyone in the project sees one warning about it, which says who can fix it. If it's on purpose, press **This is on purpose** and that warning goes away for that file. If you chose **Keep this file on this computer only** in SolidWorks, Armory still keeps it on your computer until you save it in your project's year.

**Fewer false alarms.** When Windows restarts for updates, loses power or is turned off while asleep, Armory no longer reports a crash.
