## What's new in Armory 0.5.0

Computers on 0.4.1, 0.4.2 or 0.4.3 update to 0.5.0 by themselves. Computers still on 0.3.1, 0.3.2 or 0.3.3 need `IDEAArmory-win-Setup.exe` run once, from this release; it keeps your Armory folder, your files and your sign-in.

**Lab computers share by themselves.** Nothing to set up. The first time someone else signs in to Armory on a computer, it becomes shared: whoever used it before keeps their sign-in there, and the window opens on everyone's faces, most recent first. One click on your face switches to you. No PIN unless a mentor turns PINs on for that computer.

**One folder for everyone, and nothing downloads twice.** Everyone on a computer works in the same Armory folder, one copy of each project. When you pick your name, you get the folder at once; the team's files already there are used as they are.

**Your work stays yours.** If you leave a file checked out, or a save Armory hasn't sent yet, it waits for you right where it is. It opens read-only for the next person, and Home tells them whose it is. When you pick your name again, it goes to Armory under your own sign-in, never anyone else's. Switching never closes a file you have open in SolidWorks.

**A project you're not in stays safe from you.** If you sign in on a computer where a team you're not on keeps its project, that project doesn't show in your Armory, and every file in it is read-only for you from the moment you pick your name. Nothing you change there is ever sent. If a file gets changed anyway, Armory moves that copy into the `.armory\recovery` folder and puts the team's version back as soon as someone on the team is signed in. Their waiting work comes back exactly as they left it.

**Folders of your own come home.** Older versions sometimes made a folder of your own, like `C:\IDEA\Armory-alex`. This update moves what is in them into `C:\IDEA\Armory` by itself, keeps any waiting work for the person it belongs to, and says what it did on Home. Nothing is deleted unless the same file is already in the shared folder. If two copies both have work in them, both stay, and Home tells you where.

**Every kind of file has its own icon.** Parts, assemblies, drawings and templates, eDrawings, STEP and IGES, STL and 3MF, G-code, DXF and DWG, laser jobs, PDFs, documents, spreadsheets, slides, pictures, video and ZIP files each have their own picture in the file list. Where Windows can make a preview of a file, you see the preview instead.

**Two Windows accounts on one computer.** If Armory is already open for another Windows user in the same folder, Armory says so plainly and starts by itself once that one quits.
