## What's new in Armory 0.4.3

Computers on 0.4.1 or 0.4.2 update to 0.4.3 by themselves. Computers still on 0.3.1, 0.3.2 or 0.3.3 need `IDEAArmory-win-Setup.exe` run once, from this release; it keeps your Armory folder, your files and your sign-in.

**Taskbar pins keep working after an update.** The move to the version that updates itself removed the old copy a taskbar pin pointed at, so a pinned Armory could turn into a blank button that said the program was no longer there. Armory now points any old pin back at itself, and updates keep it there. If your pin still shows a blank picture after this update, Armory tells you once how to fix it: right-click the button, choose **Unpin from taskbar**, then find IDEA Armory in Start, right-click it and choose **Pin to taskbar**.

**See which version you have.** Settings has **About this Armory**: the version, the day it was installed or updated, and this computer's name with its device tag (the same tag the website shows when two computers share a name). The tray icon's hover text says the version too. After an update, Armory says "Armory updated from 0.4.2 to 0.4.3." once.

**Lab computers copied from one image are told apart.** A lab image copied to many computers gives them the same Windows name and sometimes the same Windows id. Armory never relied on the name to tell computers apart (each sign-in has its own device), and its problem reports now also tell apart computers that share a Windows id. To rename lab computers in bulk, see `docs/LAB_COMPUTER_NAMES.md`.
