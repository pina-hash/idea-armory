## What's new in Armory 0.5.7

Computers on 0.4.1 or later update to 0.5.7 by themselves. Computers still on 0.3.1, 0.3.2 or 0.3.3 need `IDEAArmory-win-Setup.exe` run once, from this release; it keeps your Armory folder, your files and your sign-in.

**The website sees what is open.** When you open, save or close a team file in SolidWorks, Armory tells ideabosco.com. The Checked out view shows how long each file has been out, whether it is open, and "Held too long" or "Computer quiet" for one that looks stuck.

**A reminder as class ends.** Five minutes before a class period ends, Armory asks you to check in what you still have checked out, with a Check in button. The bell times come from the school calendar on the website.

**Check out and open from the website.** Check out and open on a file's page gets the newest copy, checks it out to you and opens it in SolidWorks. A file someone else has opens read-only, and Armory says who has it.

**Told when a file is checked in for you.** If a mentor, the folder's owner or your team forces in a file from your computer, Armory now also says so as a Windows notification. Your saved work is kept.

**Help the first time.** A short card explains your first check out, and the first time two people changed one file.

**Automatic check in, only if Mr. Pina turns it on.** A closed file nobody has touched for a set time can be checked in by Armory itself. It is off unless a site admin sets it.
