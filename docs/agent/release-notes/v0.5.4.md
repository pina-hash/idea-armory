## What's new in Armory 0.5.4

Computers on 0.4.1 or later update to 0.5.4 by themselves. Computers still on 0.3.1, 0.3.2 or 0.3.3 need `IDEAArmory-win-Setup.exe` run once, from this release; it keeps your Armory folder, your files and your sign-in.

**File pictures show.** Parts, assemblies and drawings show the same picture in Armory that File Explorer shows. They never showed before because the window asked for each picture at an address that never reached Armory; pictures now come from their own address.

**Find a file in a big folder.** Type in the search box to filter by file name or folder as you type, or use the quick filters: checked out by me, checked out by others, changed on this computer, and part, assembly, drawing or other. Ctrl+F jumps to the search box and Escape clears it.

**An update is not a crash.** When Armory updated itself and closed the older copy that was still running, it reported that as a crash. It now says Armory was updated.

**Better reports.** When you send a report or feedback, the first notes about file pictures go with it, so a picture problem can be traced.
