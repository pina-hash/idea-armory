## What's new in Armory 0.5.1

Computers on 0.4.1 or later update to 0.5.1 by themselves. Computers still on 0.3.1, 0.3.2 or 0.3.3 need `IDEAArmory-win-Setup.exe` run once, from this release; it keeps your Armory folder, your files and your sign-in.

**One lab computer is one computer on the website.** Armory now tells ideabosco.com which computer it is running on, so the Team view lists a lab computer once, with everyone who uses it, instead of once per person. Two lab computers set up from the same image and both named IDEA-06 show as two computers, each with its own short tag, on the Team, Files and Checked out views. Nothing to set up, and nothing changes in the Armory window.

What is sent is a code made from the computer's Windows ID and network address, never the ID or the address themselves, and the website shows a different code for the same computer in each project.
