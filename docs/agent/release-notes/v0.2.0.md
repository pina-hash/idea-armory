## Install 0.2.0 on every computer soon

Since ideabosco.com was updated for Armory 0.2.0 in October 2026, Armory 0.1.0 can put an old, removed part back over a student's new part. It happens when a student adds a file in one folder and a file with the same name was removed from another folder of the project, for example when a Pack and Go copy is unzipped again. Armory 0.1.0 then says "Someone else saved Plate.SLDPRT first. Your version is saved in its history." (with that file's name) and puts the removed part on the student's computer in place of the new one. The student's new part is not lost: it is in that file's history in Armory.

Armory 0.2.0 keeps the student's new part and continues the file's history from it. Installing 0.2.0 over 0.1.0 keeps the vault folder and the sign-in.
