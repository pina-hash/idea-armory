## What's new in Armory 0.5.9

**You can remove a file.** Open its page and choose **Move to Trash**. Type **remove** to confirm. Check the file in and close it first. This removes it for the whole team. Its history stays safe. Restore it from **Trash** on the project's website within 30 days. Copies on computers are kept safe too.

**Find your latest work.** **Sort files** offers Name, Last modified (newest first), and Last modified (oldest first). The date is the last save shared with Armory. Search results use the same order. Folders stay first.

**Empty folders can be shared.** Make one with **New folder**. Teammates can see it before you add a file. Renaming and deleting it works too. An older website says when it needs an update before it can share empty folders.

**Fewer computer problems.** A Windows startup command no longer breaks the cleanup of old Armory copies. A failed update check tries again sooner. When the server is down, Armory keeps your work here and waits longer between tries. It sends one problem report for that outage, including across restarts.

Mouse back and forward already work. So do Alt+Left and Alt+Right.

Open the flash drive in File Explorer and double-click **IDEAArmory-win-Setup.exe** from this release. It keeps the files and sign-in.
