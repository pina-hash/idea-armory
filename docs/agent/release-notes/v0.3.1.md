## What's new in Armory 0.3.1

Install 0.3.1 on every mentor's and CAD lead's computer. Installing it over 0.3.0 keeps your Armory folder, your files and your sign-in.

**Force check in all is fast now.** Force checking in a folder or a selection of many files used to go one file at a time, and each file waited on a full sync of its own, so a few hundred files could take the better part of an hour. Now Armory forces them all in one go: a few hundred files take seconds, then one sync catches everything up. When it finishes, one line says how many were force checked in, and which ones weren't (for example, a file nobody had checked out any more, or one you have checked out yourself).

Check out all, Check in all and Undo check out were already done in one go in 0.3.0, and still are.

Nothing else changes. As before, anything the holder hadn't checked in is kept on their computer as their own copy and in the file's history.
