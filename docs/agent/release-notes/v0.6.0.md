## What's new in Armory 0.6.0

**See your parts as tiles.** In Team files, choose **Tiles** for bigger pictures. **List** brings the rows back. Your choice stays yours on a shared computer. A file without a picture still shows its file type.

**Drag a file into a folder.** Drag its name onto a folder, or onto a folder name in the trail above the files. It moves within that project and keeps its history. Close the file in SolidWorks first. You can also open its page, choose **Move to folder**, then click **Move file**.

**Less scrolling for teachers.** **Condense folders** fits the folders into short rows. Every folder stays there, even an empty one. Click it again for the full rows.

**How do I upload my part?** Open your project and folder, click **Add files**, then choose your part. Armory copies it here and shares it with your team. That help now shows beside the files, and **Add files** keeps its words in a small window too.

**STEP pictures, when Windows has one.** Armory now asks Windows for a STEP picture first. If no STEP preview tool is installed, it shows the named STEP tile. It does not guess the part's shape.

**The fixes meant for 0.5.9 are here too.** Its installer build stopped, so those fixes never reached the lab. Sort by **Last modified** to find your latest work. Teammates can see shared empty folders. **Move to Trash** keeps old saves and lets you bring a file back on the website within 30 days. Failed update checks try again sooner, and server outages send fewer problem reports. Mouse back and forward still work.
